# Markdown Timetable File Creator Prompt 🤖

Copy and paste the prompt template below into any AI assistant (ChatGPT, Claude, Gemini, DeepSeek, etc.) to generate a custom Markdown timetable file formatted specifically for the **Markdown Timetable Android App**.

---

## 📋 Copy & Paste Prompt Template

```markdown
Act as a world-class mentor and curriculum designer. Please create a highly structured, day-by-day learning timetable for the subject described below. 

The output MUST follow strict Markdown formatting so that it can be parsed and rendered directly by the Markdown Timetable Android Application.

### Instructions & Parameters:
- **Subject / Topic**: [TOPIC_NAME] (e.g. "System Design & Microservices", "LeetCode 75 DSA", "Android App Development with Jetpack Compose", "Spanish Language Mastery")
- **Total Duration**: [TOTAL_DAYS] Days (e.g. 14, 30, 60, 90)
- **Target Difficulty Level**: [DIFFICULTY_LEVEL] (e.g. Beginner, Intermediate, Advanced, Elite)
- **Daily Time Commitment**: [HOURS_PER_DAY] Hours / Day (e.g. 2 hours/day)
- **Specific Focus / Goals**: [SPECIFIC_GOALS_OR_SUBJECTS] (e.g. "Focus on practical coding problems, official documentation, and real-world system architecture")

---

### Strict Markdown Syntax Rules:
1. **Days (Level 1 Heading)**: Every day MUST start with a Level 1 Heading (`# Day X: Title`).
2. **Topics (Level 2 Heading)**: Under each Day, divide the work into 1 to 3 distinct Topics using Level 2 Headings (`## Topic Y: Section Name`).
3. **Subtopics / Tasks (Bullet Checklist)**: Under each Topic, list individual tasks using Markdown bullet point checkboxes (`* [ ] Task item text`).
4. **Clickable Links**: Include 1 to 3 real, high-quality Markdown links for practice problems, official documentation, articles, or tutorials. Format links strictly as `[Link Label](https://url)`. Do not use citations like `[cite: 1]`.

---

### Example Output Format Expected:

# Day 1: Fundamentals & Setup
## Topic 1: Environment & Tooling
* [ ] Install required SDKs and IDE tools
* [ ] Read Official Overview - [Official Documentation](https://developer.android.com)

## Topic 2: Core Concepts Practice
* [ ] Solve Practice Problem 1 - [Practice Link](https://leetcode.com/problems/two-sum/)
* [ ] Solve Practice Problem 2 - [Practice Link](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/)

# Day 2: Advanced Data Structures
## Topic 1: Deep Dive
* [ ] Study Internals & Trade-offs - [In-depth Guide](https://www.baeldung.com)
* [ ] Complete Coding Exercise - [Exercise Link](https://leetcode.com/problems/valid-palindrome/)

---

Please generate the complete, comprehensive [TOTAL_DAYS]-Day timetable following these exact rules now:
```

---

## 💡 How to Use the Generated Output in the App

1. Copy the Markdown text generated by the AI assistant.
2. Open the **Markdown Timetable** app on your phone.
3. Tap the **`+`** Floating Action Button at the bottom-right corner of the Home Screen.
4. Select **Paste / Type Markdown Text**.
5. Give your timetable a custom title (e.g. `System_Design_30_Days.md`).
6. Paste the generated Markdown content into the text area and tap **Load Timetable**.
7. Your custom study plan is now rendered with interactive checkboxes, clickable links, auto-scrolling to the next incomplete day, and exact daily notification reminders!
